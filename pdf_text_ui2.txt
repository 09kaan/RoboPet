2. The Flame canvas
lib/game/robot_game.dart
A transparent FlameGame (so the HUD gradient shows through) hosting a glowing platform + a robot 
that breathes (scale sine) and bobs (vertical sine). RobotStage creates the game ONCE so the 
frequent Riverpod rebuilds never recreate it.
import 'dart:math' as math;
 
import 'package:flame/components.dart';
import 'package:flame/game.dart';
import 'package:flutter/material.dart';
 
/// A lightweight Flame canvas hosting the robot avatar. For now it renders an
/// animated (breathing + bobbing) placeholder; swap in real sprites later.
class RobotGame extends FlameGame {
  RobotGame({this.accent = const Color(0xFF22E1FF)});
 
  final Color accent;
 
  @override
  Color backgroundColor() => const Color(0x00000000); // transparent
 
  @override
  Future<void> onLoad() async {
    await super.onLoad();
    add(GlowPlatform());
    add(RobotAvatar());
  }
}
 
/// Soft glowing pad the robot stands on.
class GlowPlatform extends PositionComponent with HasGameReference<RobotGame> {
  @override
  void onLoad() {
    anchor = Anchor.center;
    size = Vector2(200, 46);
    position = Vector2(game.size.x / 2, game.size.y / 2 + 96);
  }
 
  @override
  void onGameResize(Vector2 s) {
    super.onGameResize(s);
    position = Vector2(s.x / 2, s.y / 2 + 96);
  }
 
  @override
  void render(Canvas canvas) {
    final rect = Rect.fromLTWH(0, 0, size.x, size.y);
    canvas.drawOval(
      rect,
      Paint()
        ..shader = RadialGradient(
          colors: [game.accent.withOpacity(0.5), Colors.transparent],
        ).createShader(rect),
    );
  }
}
 
/// The breathing / bobbing robot placeholder.
class RobotAvatar extends PositionComponent with HasGameReference<RobotGame> {
  double _t = 0;
 
  @override
  void onLoad() {
    anchor = Anchor.center;
    size = Vector2(150, 150);
    position = game.size / 2;
  }
 
  @override
  void onGameResize(Vector2 s) {
    super.onGameResize(s);
    position = s / 2;
  }
 
  @override
  void update(double dt) {
    super.update(dt);
    _t += dt;
    scale = Vector2.all(1 + 0.045 * math.sin(_t * 2.2)); // breathe
    position = game.size / 2 + Vector2(0, 7 * math.sin(_t * 1.6)); // bob
  }
 
  @override
  void render(Canvas canvas) {
    final w = size.x;
    final h = size.y;
    final accent = game.accent;
 
    final body = RRect.fromRectAndRadius(
      Rect.fromLTWH(w * 0.16, h * 0.22, w * 0.68, h * 0.6),
      const Radius.circular(30),
    );
 
    // Outer glow.
    canvas.drawRRect(
      body,
      Paint()
        ..color = accent.withOpacity(0.45)
        ..maskFilter = const MaskFilter.blur(BlurStyle.normal, 20),
    );
    // Body fill.
    canvas.drawRRect(
      body,
      Paint()
        ..shader = const LinearGradient(
          begin: Alignment.topCenter,
          end: Alignment.bottomCenter,
          colors: [Color(0xFF1B2740), Color(0xFF0C1322)],
        ).createShader(body.outerRect),
    );
    // Neon border.
    canvas.drawRRect(
      body,
      Paint()
        ..style = PaintingStyle.stroke
        ..strokeWidth = 2.2
        ..color = accent,
    );
 
    // Antenna.
    final pen = Paint()
      ..color = accent
      ..strokeWidth = 3
      ..strokeCap = StrokeCap.round;
    canvas.drawLine(Offset(w * 0.5, h * 0.22), Offset(w * 0.5, h * 0.08), pen);
    canvas.drawCircle(Offset(w * 0.5, h * 0.06), 5, Paint()..color = accent);
 
    // Eyes (glow + white core).
    final eyeY = h * 0.46;
    final glow = Paint()
      ..color = accent
      ..maskFilter = const MaskFilter.blur(BlurStyle.normal, 4);
    for (final dx in [0.40, 0.60]) {
      canvas.drawCircle(Offset(w * dx, eyeY), 9, glow);
      canvas.drawCircle(Offset(w * dx, eyeY), 5, Paint()..color = Colors.white);
    }
 
    // Mouth.
    canvas.drawRRect(
      RRect.fromRectAndRadius(
        Rect.fromLTWH(w * 0.40, h * 0.62, w * 0.20, h * 0.04),
        const Radius.circular(4),
      ),
      Paint()..color = accent.withOpacity(0.8),
    );
  }
}

  @override
  Widget build(BuildContext context) => GameWidget(game: _game);
}

/// Reusable glassmorphism container: blurred translucent fill + glowing border.
class GlassPanel extends StatelessWidget {
  const GlassPanel({
    super.key,
    required this.child,
    this.padding = const EdgeInsets.all(16),
    this.radius = 18,
    this.blur = 14,
    this.borderColor = Colors.white24,
    this.glow = false,
  });
 
  final Widget child;
  final EdgeInsets padding;
  final double radius;
  final double blur;
  final Color borderColor;
  final bool glow;
 
  @override
  Widget build(BuildContext context) {
    return ClipRRect(
      borderRadius: BorderRadius.circular(radius),
      child: BackdropFilter(
        filter: ImageFilter.blur(sigmaX: blur, sigmaY: blur),
        child: Container(
          padding: padding,
          decoration: BoxDecoration(
            borderRadius: BorderRadius.circular(radius),
            gradient: LinearGradient(
              begin: Alignment.topLeft,
              end: Alignment.bottomRight,
              colors: [
                Colors.white.withOpacity(0.08),
                Colors.white.withOpacity(0.02),
              ],
            ),
            border: Border.all(color: borderColor, width: 1.2),
            boxShadow: glow
                ? [
                    BoxShadow(
                      color: borderColor.withOpacity(0.4),
                      blurRadius: 18,
                      spreadRadius: -2,
                    ),
                  ]
                : null,
          ),
          child: child,
        ),
      ),
    );
  }
}

class PetScreen extends ConsumerWidget {
  const PetScreen({super.key});
 
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final asyncRobot = ref.watch(activeRobotStreamProvider);
 
    return Scaffold(
      body: asyncRobot.when(
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (e, _) => Center(child: Text('Error: $e')),

            ? const Center(child: Text('No active robot'))
            : _PetView(robot: robot),
      ),
    );
  }
}

class _HudStatBar extends StatelessWidget {
  const _HudStatBar({
    required this.label,
    required this.value,
    required this.max,
    required this.color,
  });
 
  final String label;
  final double value;
  final double max;
  final Color color;
 
  @override
  Widget build(BuildContext context) {
    final pct = (value / max).clamp(0.0, 1.0);
    final text = Theme.of(context).textTheme;
 
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Row(
          children: [
            Text(label.toUpperCase(),
                style: text.titleSmall?.copyWith(letterSpacing: 1.5)),
            const Spacer(),
            Text('${(pct * 100).round()}%',
                style: text.titleSmall
                    ?.copyWith(color: color, fontWeight: FontWeight.w700)),
          ],
        ),
        const SizedBox(height: 6),
        Container(
          height: 14,
          decoration: BoxDecoration(
            borderRadius: BorderRadius.circular(8),
            color: Colors.white.withOpacity(0.06),
            border: Border.all(color: color.withOpacity(0.35)),
          ),
          child: ClipRRect(
            borderRadius: BorderRadius.circular(8),
            child: Align(
              alignment: Alignment.centerLeft,
              child: TweenAnimationBuilder<double>(
                tween: Tween<double>(begin: 0, end: pct),
                duration: const Duration(milliseconds: 500),
                curve: Curves.easeOut,
                builder: (context, v, _) => FractionallySizedBox(
                  widthFactor: v <= 0 ? 0.001 : v,
                  child: Container(
                    decoration: BoxDecoration(
                      gradient: LinearGradient(
                        colors: [color.withOpacity(0.65), color],
                      ),
                      boxShadow: [
                        BoxShadow(color: color.withOpacity(0.6), blurRadius: 10),
                      ],
                    ),
                  ),
                ),
              ),
            ),
          ),
        ),
      ],
    );
  }
}

class _GridPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..color = Colors.cyan.withOpacity(0.05)
      ..strokeWidth = 1;
    const step = 34.0;
    for (double x = 0; x < size.width; x += step) {
      canvas.drawLine(Offset(x, 0), Offset(x, size.height), paint);
    }
    for (double y = 0; y < size.height; y += step) {
      canvas.drawLine(Offset(0, y), Offset(size.width, y), paint);
    }
  }
 
  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

6. Phase 2 -- Technical outline (Firebase, Gacha, Modules)
A brief approach before we dive in. Phase 2 turns the single local pet into a collection backed by a 
server-authoritative economy.
6.1 Firebase Auth & cloud sync
 Anonymous-first auth: signInAnonymously() on launch; replace the hardcoded local-player with 
the real uid. Offer account linking (Apple/Google) later so progress survives reinstalls.
 Authority split: Isar stays local-authoritative for care/decay (offline-first). Firestore is 
authoritative for the economy -- currencies, owned robots, owned modules, gacha pulls. A thin 
sync layer mirrors PlayerProfile to users/{uid} and hydrates Isar on login.
 Conflict rule: care stats reconcile via the existing timestamp engine; economy fields are only ever 
mutated server-side, so the client never wins a currency conflict.
6.2 Cloud Functions for Gacha (anti-cheat core)
 Callable function rollGacha({ lootTableId, count }). The client NEVER computes a draw. The 
function:
 Reads the player doc in a Firestore transaction.
 Validates currency (e.g. enough scrap/rareCogs); rejects otherwise.
 Runs the weighted draw + pity server-side (e.g. epic guaranteed at pull 30), seeded server-
side.
 Writes new robot/module instances to inventory + decrements currency atomically.
 Returns the resolved results for the client to animate.
 Loot tables live in Firestore/Remote Config so drop rates are tunable without an app release.
 Hardening: server timestamps only; never trust client time for rewards; reject premium-currency 
mutations that do not originate from a verified IAP/earn event.
6.3 Modules system
 Definition vs instance: ModuleDef (static content -- type, slot, stat modifiers, rarity) in Firestore; 
ModuleInstance in the player inventory (Isar + Firestore).
 Equip/unequip updates the robot Loadout slot (wheels/armor/sensor/core/utility) -- already in 
our schema.
 Derived stats: recompute on equip as base + sum(flat), then x(1 + sum(percent)); never persist 
derived values (compute on read), so re-balancing is just a data change.
 UI: a collection/inventory grid + a module loadout screen, both reading the same reactive 
providers pattern we built in Phase 1.
6.4 Suggested build order
 Firebase project + anonymous auth + PlayerProfile <-> Firestore sync.
 Inventory & ModuleDef/ModuleInstance data model (extend Isar + Firestore).
 rollGacha Cloud Function + loot tables + currency validation.
 Gacha reveal animation (Flame) + collection grid.
 Module equip screen + derived-stat recompute.
When you are ready, the full Phase 2 TDD (schemas, the rollGacha function signature + transaction 
logic, and the sync layer) can be produced as its own document -- and exported to PDF.
